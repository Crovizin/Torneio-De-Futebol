Sistema de Simulação de Torneio Mundial de Futebol

Autores:
Raphael de Almeida Cruz; RGA: (202421901060);
Nicolas Oliveira Dos Santos; RGA: (202421901054);

Linguagem:
Java

Descrição:

O sistema realiza:

- Cadastro de juízes
- Pesquisa de clubes
- Sorteio automático dos grupos
- Simulação da fase de grupos
- Simulação do mata-mata
- Sorteio de árbitros para as partidas
- Exibição do campeão

Conceitos utilizados:

- Encapsulamento
- Herança
- Polimorfismo
- Tratamento de exceções
- Interface gráfica Swing
- Persistência de dados
